Este site

Site para mostrar minhas habilidades com Spec-Driven Development e apresentar, de forma detalhada, pontos da minha carreira.

Ver no GitHub Contato
01

Objetivo

Um portfólio estático, rápido e acessível, que mostra o trabalho com evidência e não com adjetivo. Também é onde aplico, em escala pequena, o mesmo processo que levo para produção.

02

Decisões

A dor

Um currículo não mostra como eu trabalho. Faltava um lugar para provar minhas habilidades com evidência, e não com adjetivo.

Construir

Um portfólio estático, rápido e acessível: Next.js App Router com Server Components por padrão, MVVM com fronteiras impostas pelo ESLint e todo texto em src/content/, sem texto fixo nos componentes.

Mostrar

Como uso o Spec-Driven Development em um site institucional: spec antes do código, teste vermelho primeiro e commits pequenos. A IA executa; eu decido a arquitetura e reviso cada mudança.
