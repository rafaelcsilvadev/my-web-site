04 · Método (SDD)

Especificação antes do código

Eu decido, a IA executa, e cada PR passa por mim antes do merge. Esse é o ciclo do My Trello Version.

  1. 01Spec
    EuDecido o que cada feature precisa.
    IACria a spec de cada feature.
  2. 02Design
    EuDecido a arquitetura e os contratos.
  3. 03Tarefas
    EuAprovo o recorte: uma tarefa por branch e por PR.
  4. 04Teste vermelho
    EuReviso os testes no PR.
    IACria os testes com TDD: o teste vermelho vem antes do código.
  5. 05Código
    EuExijo commits pequenos.
    IAImplementa até o teste passar.
  6. 06PR com revisão humana
    EuReviso cada Pull Request antes do merge.
    IAAbre o PR com o resumo das mudanças.
